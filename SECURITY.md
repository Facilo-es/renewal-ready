# Security

Please report security problems to support@facilo.es. We answer within 2 working days.

Support period: each Renewal Ready release gets security fixes for 5 years from its release date. Renewal Ready Pro gets security fixes for 5 years from purchase, and they reach lapsed Pro licences on request.

The software bill of materials is in `sbom.cdx.json` (CycloneDX 1.5).
